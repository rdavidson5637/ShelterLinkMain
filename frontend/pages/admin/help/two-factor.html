How to turn on two-factor sign-in

Staff and admin accounts can see vetting details. A code from an authenticator app means a stolen password is not enough.

  1. Open Sign-in security

    Under Insight in the admin menu. Volunteers do not use this page.

  2. Turn on two-factor sign-in

    Confirm your password, then scan the QR code with an authenticator app on your phone.

  3. Enter the six-digit code

    The app shows a code that changes every half minute. Enter it to finish setup.

  4. Save the recovery codes

    Store them somewhere safe offline. Each code works once if you lose the phone.

  5. Next sign-in

    After your password you will be asked for the app code. Keep the app on a phone you bring to work.
