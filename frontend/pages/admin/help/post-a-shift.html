How to post a shift

Put an open shift on the board so volunteers can apply.

  1. Open Create opportunity

    From Shifts, tap Create opportunity. Or start here from the link below.

  2. Use a template if you have one

    Pick a template to fill title, description, location, and requirements. Dates stay blank so you set them for this run.

  3. Fill the basics

    Title, description, location, start and end date and time, and how many people you need.

  4. Add gates if the shift needs them

    Required skills, AccessNI, waiver, animals, or age rules. Volunteers who do not meet them cannot apply.

  5. Publish

    Save the opportunity. It shows on Shifts and on the public board when the shelter is live.

  6. Need the same shift again?

    On Shifts, use Duplicate, or start from the same template next time.
