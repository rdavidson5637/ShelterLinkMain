How to set shift skills

Each shelter names its own skills (dog walking, cattery, reception, and so on). Tag shifts with what they need, then record those skills on volunteers so booking only offers shifts they can do.

  1. Open Skills

    Under Manage, open Skills. The list is for this shelter only, not a fixed global list.

  2. Add the skills you use

    Name each skill clearly. Leave validity blank unless the skill should expire after training.

  3. Tag a shift

    When you create or edit a shift, choose Required skills. Volunteers without them cannot book it.

  4. Record skills on a volunteer

    On the volunteer profile, award the skill. They then see that shift when they browse.

  5. What volunteers see

    Find shifts shows only shifts they are eligible for by default. They can tick a box to see the others, each with a clear reason naming the missing skill.
