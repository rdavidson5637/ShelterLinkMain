How to set up training modules

Short modules with a pass mark. Passing can award a qualification that already gates shifts.

  1. Admins only

    Training modules sit under Manage for admin accounts.

  2. Add a module

    Name it clearly (for example Dog walking level 1). Add a short description volunteers will see.

  3. Set the pass mark and content

    Write the questions or material and the score they need to pass.

  4. Link a qualification

    When someone passes, award a qualification you already use to gate shifts. Create the qualification first if it does not exist yet.

  5. Publish

    Save the module. Volunteers see it under Training. Shifts that require that qualification stay blocked until they pass.
